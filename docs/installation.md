# Instalação — moodle-tool_participantscustomfilter

## Procedimento de Instalação

1. Clone o repositório no diretório de ferramentas de administração:
   ```bash
   cd /caminho/do/moodle/admin/tool
   git clone https://github.com/moodle-by-kelsoncm/moodle-tool_participantscustomfilter.git participantscustomfilter
   ```
2. Execute a atualização via CLI:
   ```bash
   php admin/cli/upgrade.php --non-interactive
   ```
